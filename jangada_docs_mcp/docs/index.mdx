  Observability nativa em 1 linha no `.env`. Troque **provider, modelo e chave** sem mudar o resto do código, com templates `{{ }}`, structured output (Pydantic), vision, áudio, tools, MCP, RAG, agentes, async, retry e fallback por erro. Funciona com Anthropic, OpenAI, Groq, Gemini, Mistral, OpenRouter, DeepSeek, Ollama e os gateways de nuvem (AWS Bedrock, Azure OpenAI e Vertex AI).
</DocsIntro>
