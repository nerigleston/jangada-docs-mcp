The [observability](/docs/observability) dashboard has its own MCP server. It lets
your AI assistant read your organization's data and answer questions like:

- "How much did I spend per model in the last 30 days, in USD and BRL?"
- "Which end users cost the most this month?"
- "Was there an error or latency spike in the last hour?"
- "Give me the total traces and average cost of the Pharmacy project in October."

Every tool is **read-only**: the MCP never changes anything in the dashboard.

## Server URL

```
https://observability.mcp.jangada.dev.br/mcp
```

Sign-in uses your Jangada AI account (the same one as `app.jangada.dev.br`). When
authorizing, you choose **which organizations** the app will read. The default is **all
your organizations**, including the ones you join later. Each one keeps its own rules:
the app only uses the tools and projects it enabled.

## Connect

### Claude (claude.ai and desktop app)

1. Open **Settings › Connectors** and click **Add custom connector**.
2. Give it a name (e.g. *Jangada Observability*) and paste the URL above.
3. Click **Connect**. The Jangada AI sign-in opens: sign in, pick the organizations and authorize.
4. In a chat, enable the connector in the tools menu and ask your question.

On Team and Enterprise plans, a Claude admin adds the connector for the team and each
person signs in.

### ChatGPT

1. Open **Settings › Apps & Connectors › Advanced settings** and turn on **Developer mode**.
2. Go back to **Apps & Connectors** and click **Create**.
3. Fill in the name, paste the URL above and keep authentication as **OAuth**.
4. Click **Connect**, sign in with your Jangada AI account and pick the organizations.
5. In a chat, pick the connector under **+ › More**.

Developer mode is available on Plus, Pro, Business, Enterprise and Edu. Menu names may
change with the ChatGPT version.

### Claude Code

```bash
claude mcp add --transport http jangada-obs https://observability.mcp.jangada.dev.br/mcp
```

Then run `/mcp` inside Claude Code and choose **Authenticate** to sign in through the
browser.

### Cursor

In **Cursor Settings › MCP › Add new MCP server**, or in `~/.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "jangada-obs": {
      "url": "https://observability.mcp.jangada.dev.br/mcp"
    }
  }
}
```

Cursor opens the Jangada AI sign-in on the first connection.

### Clients without OAuth (static token)

An OWNER or ADMIN creates a token under **MCP › Static tokens** in the dashboard. The
client sends it in the header:

```
Authorization: Bearer jomcp_...
```

The token works for the whole organization, with the same tools and projects enabled in
the dashboard. It is shown only once; revoke it when no longer needed.

## Tools

| Tool | Returns |
|------|---------|
| `listar_projetos` | Projects the MCP can read and the date of each one's last trace |
| `metricas` | Cost in USD and BRL, calls, tokens (input, output, reasoning, cache), error rate, p50/p95/p99 latency and cost per model, provider, capability and day |
| `anomalias` | Last hour error rate, last 24 h p95 latency and today's cost, compared with the 7-day average |
| `listar_traces` | Traces with the Traces tab filters (model, provider, status, user, session, capability, period), paginated |
| `totais_traces` | Totals for **every** trace in the filter, without pagination, broken down by day (the period's financial summary) |
| `detalhe_trace` | Each call of a trace: model, tokens, cost, latency, error and scores. Input and output only if the organization allows it |
| `custo_por_usuario` | Cost ranking per end user (the `user_id` your app sends to jangada) |

The tools take `projeto` (name or id). With several organizations in the connection, use
`"Org / Project"` when names repeat. With a single enabled project, it is used
automatically. Periods take `dias` (window up to now) or `de`/`ate` in ISO (`2026-09-01`).
Tool and parameter names are in Portuguese, like the rest of the platform.

The BRL cost uses the Central Bank of Brazil PTAX selling rate of **each call's day**
(Brasília time), same as the dashboard.

## Configure per organization

In the dashboard, the **MCP** sidebar menu controls each organization's access:

- **On or off.** Turning it off cuts every connection and token of the organization right away.
- **Enabled tools.** An unchecked tool disappears from the assistant's list and the API
  refuses the call.
- **Projects.** All (including ones created later) or only the selected ones.
- **Call input and output.** When on, `detalhe_trace` returns the messages sent to and
  received from the model.
- **Connections.** Who connected, from which app and when it was last used, with a
  revoke button. Revoking on one organization's page removes only that organization
  from the connection; if it covers others, it keeps working there.
- **Static tokens.** Create and revoke.

By default the MCP is **on in every organization, with every tool**, and call
input/output is **off**. Only OWNER and ADMIN can change the settings; any member can
connect and revoke their own connection.

<Callout type="warn">
Your users' conversations may contain personal data. When you turn on input and output,
those messages go to the AI assistant of whoever connects the MCP.
</Callout>

Settings changes reach the assistant within 60 seconds.

## Security

- Sign-in is OAuth 2.1 with PKCE. The app gets a 1-hour access token and a rotating
  30-day refresh token. Replaying a used refresh token revokes the whole authorization.
- The authorization screen shows the **domain** of the requesting app, which can't be forged.
- Every call checks again that the user is still a member of the organization and that
  the tool and project are still enabled.
- The server runs on [jangada Cloud](https://app.mcp.jangada.dev.br) in external OAuth
  mode, built with jangada's own [`build_mcp_app`](/docs/mcp).

## Troubleshooting

| Symptom | What to do |
|---------|------------|
| The organization is disabled on the authorization screen | The MCP is off there. An OWNER or ADMIN turns it on under **MCP** in the dashboard |
| "ferramenta desconhecida" (unknown tool) | The tool was turned off in the organization (or the change hasn't arrived yet: wait 1 minute) |
| "projeto não encontrado ou não liberado" | The project is not in the MCP list. The message includes the available projects |
| The assistant asks to sign in again | The connection was revoked, the refresh token expired or you left the organization |
