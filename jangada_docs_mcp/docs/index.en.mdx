  Native observability in one line of your `.env`. Swap **provider, model and key** without touching the rest of your code, with `{{ }}` templates, structured output (Pydantic), vision, audio, tools, MCP, RAG, agents, async, retry and error-based fallback. Works with Anthropic, OpenAI, Groq, Gemini, Mistral, OpenRouter, DeepSeek, Ollama and the cloud gateways (AWS Bedrock, Azure OpenAI and Vertex AI).
</DocsIntro>
